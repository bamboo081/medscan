# GitHub commit and release plan

Published repository: https://github.com/bamboo081/medscan (public). The prepared source release was committed and pushed to `main` on 2026-11-06. The checklist below records the preparation and documents future release steps. GitHub Actions status is available at https://github.com/bamboo081/medscan/actions.

## Prepared product

MedScan is an MIT-licensed source release for local, non-clinical MRI/CT/X-ray research. It includes training, caching, leakage-aware preparation, evaluation, inference, a localhost Gradio demo, tests, model cards and aggregate benchmark reports. It contains no source scans, patient identifiers, per-image predictions, cached tensors or model weights.

The recommended release title is **MedScan research prototype — evaluated modality-specific baselines**. Suggested tag: `v0.1.0`. The results support an educational/research release, not a claim of diagnostic reliability or blanket performance improvement. README.md explains installation and operation; RESULTS.md contains the mixed results and limitations.

## Push to GitHub

Choose your repository owner/name and visibility. Create an empty GitHub repository without an autogenerated README or license, since this source already contains both. Then replace the placeholder URL:

```bash
git remote add origin https://github.com/YOUR_ACCOUNT/medscan.git
git push -u origin main
```

If `origin` already exists, inspect it with `git remote -v` rather than replacing it blindly. Wait for GitHub Actions CPU tests to pass. GitHub Actions has not been run remotely by this preparation.

After the first push and CI success, add a version tag and create the GitHub release:

```bash
git tag -a v0.1.0 -m "MedScan non-clinical research prototype"
git push origin v0.1.0
```

Use RESULTS.md as the release-note source. Publish the source archive/checksum if desired. Do not upload `.pt` weights or dataset examples under the code license without separately establishing redistribution rights. The aggregate reports already provide provenance without those artifacts.

## What remains outside this release

- External patient-indexed evaluation, calibration, domain-expert review and clinical validation.
- Verified patient independence for kidney CT; proxy grouping cannot supply it.
- Better rare-label X-ray performance, particularly pneumonia, through future validation-led research rather than tuning to the published test scores.
- MRI healthy/normal detection: the training task has no such class.
- Automatic modality routing, 3D imaging, optimizer-state resume and public hosting.

These are documented boundaries of the research product rather than promises included in v0.1.0.
